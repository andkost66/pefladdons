# CrabVIP 2.1.3 — установка и проверка

Подготовлено 4 ноября 2026 года. Это сборка для ручной проверки в Chrome, не публикация Chrome Web Store. Автоматические проверки описаны в VALIDATION.md. В пользовательском Chrome эта сборка ещё не установлена.

## Установка

1. Распакуйте `CrabVIP-2.1.3.zip` в постоянную папку. Внутри папки `CrabVIP-2.1.3` находится `manifest.json`.
2. В Chrome откройте `chrome://extensions`. Если старая версия уже загружена из распакованной папки, сначала сохраните копию этой папки, затем замените её содержимое новой сборкой и нажмите кнопку обновления расширения. Для отдельной установки выключите старую копию, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку с новым `manifest.json`.
3. Перезагрузите страницу команды PEFL. На панели справа нажмите «Скачать резервную копию». Перед первым изменением истории новая версия также сохраняет её локальный снимок автоматически.
4. Проверьте, что у расширения указана версия 2.1.3, активна одна копия CrabVIP и у «Основного состава» появляется «загружено». При неполной загрузке будет показано число карточек и ссылка «повторить»; наведение показывает причину.

Используйте тот же профиль Chrome и тот же адрес PEFL (например, `https://pefl.ru`), где находилась старая история: данные сайтов `pefl.ru`, `pefl.org` и адресов с `www` хранятся раздельно. Кнопка резервного копирования сохраняет localStorage текущего сайта, включая настройки и историю матчей; она не экспортирует cookies и IndexedDB. Файл резервной копии может содержать игровые заметки и ссылки — храните его у себя.

[Инструкция Chrome: установка распакованного расширения](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

## Сбор минут

Сначала откройте страницу своей команды: расширение определит клуб и запомнит соответствие имён и ID игроков. После открытия завершённого протокола матча своего клуба появится сообщение `CrabVIP 2.1.3: минуты матча сохранены`. Повторное открытие обновляет запись без дубликатов.

Без VIP можно открыть карточку своего игрока, вкладку «Матчи», затем нажать «Собрать минуты клуба из показанных матчей». Будут обработаны только ссылки, показанные на этой вкладке: это не полный сезон клуба. Альтернатива — вставить доступные ссылки в «Импорт по ссылкам на протоколы» на странице команды. Максимум 100 разных протоколов за один запуск. Номер `n` из ссылки игрока сохраняется вместе с ней.

«Из расписания (VIP)» использует доступное аккаунту расписание. Если PEFL показывает VIP-ограничение, расширение объясняет это и не продолжает импорт этой страницы.

В таблице «Сверхусталость» показываются минуты из сохранённых протоколов. Новые записи включают добавленное время: например, в протоколе Майнц — Штутгарт №1544766 полный матч составляет 93 минуты. Замены и удаления учитываются отдельно для каждого игрока. Незавершённые протоколы, чужой клуб и нераспознанные события не сохраняются.

## Границы расчёта и сохранность истории

3600 минут — старый ориентир CrabVIP, а не установленный этой работой официальный порог PEFL. Проценты практики приблизительны: они зависят от полноты истории и текущего состава. Товарищеские без потери сыгранности и неподходящие записи прошлых сезонов требуют ручного исключения. Автоматического определения всего сезона и официальной скрытой сверхусталости нет.

Старая история сохраняется. При повторном импорте остаются даты, типы матчей и ручные исключения. При неоднозначном совпадении имён стоит проверить записи вручную. Старые записи без точных минут могут содержать прежнюю оценку до повторной загрузки протокола. Повреждённый JSON не перезаписывается. На случай ошибки сохранения предыдущие значения находятся в `crabSuRecovery`; первый снимок версии — в `crabSuBackupV213`.

Для отката отключите новую копию и включите сохранённую старую версию либо верните прежние файлы в её папку и обновите расширение. Откат программы сам по себе не откатывает записи матчей; исходную историю сохраняет резервная копия. Очистка данных сайта удаляет локальную историю.
