# Проверка CrabVIP 2.1.3

Дата: 2026-11-04. Ветка: `fix/crabvip-recovery-2026-11-04`.

## Что восстановлено

Работа основана на коде PR #1 (панель команды) и PR #2 (сбор минут) репозитория `andkost66/pefladdons`. Упоминавшаяся в прежней переписке локальная версия 2.1.2 не найдена в доступном репозитории; её заявленные результаты тестов не используются как доказательство.

- Загрузка современной карточки игрока: 18 базовых скиллов, сумма, зарплата, номинал и контракт. Скрытые дополнительные скиллы вратаря и поправки формы не включаются в сумму.
- GET-запросы текущего сайта через XMLHttpRequest учитывают кодировку ответа PEFL; скрипты расширения явно загружаются как UTF-8 в установленном порядке. Ошибки сервера, таймаут, выход из аккаунта и VIP-страница различаются.
- Сортировка списка больше не переставляет элементы массива, индексированного ID игрока.
- Минуты берутся из интервалов участия в завершённом протоколе; игровой номер не используется как номер места в составе. Учтены добавленное время, замены, удаления, домашняя/гостевая сторона.
- Добавлены сбор из вкладки «Матчи» карточки, ручной импорт ссылок, резервная копия и защита старой истории. Автоматического удаления истории при смене сезона нет.
- Исправлена совместимость нового блока импорта с карточкой игрока и обработка недоступных данных внешней оценки номинала. Имена с кавычками не ломают ссылки таблицы минут.

## Проверки

`npm test`: 34 теста парсеров, миграции и сохранения данных. Реальные обезличенные снимки: Майнц — Штутгарт №1544766, Лотте — Майнц №1544756, Майнц — Вупперталь №1544744; современные карточки вратаря и полевого игрока. Дополнительное время 123 минуты и редкие повторные замены проверяются синтетическими изменениями снимков, а не заявляются реальными матчами.

`npm run test:browser`: 14 интеграционных проверок в отдельном Chromium 133.0.6943.0. Проверяются настоящие скрипты и загрузчик расширения, интерфейсы команды, карточки и протокола; 24/24 карточки, UTF-8 скрипты на windows-1251 странице, обе средние суммы скиллов, повторный импорт, ручной импорт, загрузка резервной копии, ошибка одной карточки и повторная попытка, безопасные имена, выключение модуля, отсутствие ошибок JavaScript и запросов записи.

Все запросы тестового браузера перехвачены локально. Для 24 строк состава ответы используют две контрольные карточки: это проверка расчёта, не настоящая сумма стоимости и зарплат клуба. Неизменённая таблица адаптации заменена тестовыми данными. Никакой пользовательский профиль, cookies или авторизация не переносились. Установка MV3-пакета и ограничения `chrome-extension://` этими тестами не проверяются: загрузчик запускается с тестовым адресом ресурсов.

`npm run check`: проверка синтаксиса всех JavaScript-файлов расширения и наличия ресурсов manifest. Архив содержит готовую папку расширения и две инструкции; тестовые данные и зависимости в архив не входят.

## Что проверено в пользовательском Chrome

Прочитаны страницы клуба, две современные карточки, список матчей игрока и три указанных протокола. Подтверждены существовавшие ошибки «карточки 0/24» / «Failed to fetch», VIP-ограничение расписания, доступность списка матчей игрока без VIP и 93 минуты в истории вратаря. Из этих наблюдений нельзя установить единственную причину старого `Failed to fetch`.

Новая сборка в пользовательский Chrome не установлена. Доступ автоматизации к `chrome://extensions` отклонён: доступны только HTTP/HTTPS-страницы. Поэтому успешная авторизованная загрузка новой версией 24 реальных карточек и импорт всей личной истории остаются финальной проверкой после ручной установки. Готовность всех остальных старых модулей CrabVIP этим набором не заявляется. Ветка `master` не менялась.

## Повторение разработчиком

Требуются Node.js (проверено 24.22.1) и Python 3 для упаковки.

```sh
npm ci
npm test
npm run check
npx playwright install chromium
npm run test:browser
npm run build
```

Можно указать существующий отдельный Chromium через `CRAB_TEST_CHROMIUM=/path/to/chromium npm run test:browser`. В среде этой проверки штатная загрузка браузера Playwright возвращала HTML вместо ZIP; использован Chromium 133 из npm-пакета `@sparticuz/chromium@133.0.0`. Это ограничение тестового окружения, не пользовательского Chrome. Скрипт не запускает пользовательский профиль и не обращается к реальному PEFL.
